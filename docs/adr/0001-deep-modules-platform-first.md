# Deep-module toolkit, platform-first, not a Lodash replacement

mxs is a personal toolkit of deep modules for Node and React, published publicly as a side effect. A module ships only if it passes the deletion test across 2+ real projects, has no native equivalent in Node 24+ or modern browsers, and adds zero runtime dependencies. Generic one-liner utils are rejected: the space is saturated (es-toolkit, remeda, radash) and native JS covers most of Lodash. Breaking changes go through semver and a changelog.
